# New Task · 外部编排档

> **适用范围**：本工单面向**被外部编排器派发的执行 agent**（pipeline 派发、空树 git worktree）。kit 自安装项目走 `.agents/commands/new-task.md` 完整协议，两者不混用。
> **交付环境**：空树 git worktree 基线；无外部需求文档；上下文由编排方注入。工单之外不存在权威信息源，缺什么向编排方要，不自行探索。

## 任务目标

- **本节由编排方注入**：目标 / 背景 / 锚点（涉及文件与模块）。
- **不自行扩充目标**：注入缺失或含糊时向编排方回报，不自行补齐、不改写目标。

## 交付要求

- **只做任务目标列出的改动**：目标之外的顺手改动一律不做。
- **交付物必须落盘**：回合内口头完成不等于交付，全部改动以文件形式写入工作区（回合完成≠交付落盘）。
- **完成后向编排方回报**：改动文件清单；验证方式与结果；偏离任务目标之处（如有）；缺失的上下文（如有）。run 状态信息以编排方注入为准，不自行生成。

## 范围边界（硬约束）

- **禁止读取编排方管控面**：不读 `.git/`；不读各类台账（`*.jsonl`，如 events / confirmations / verifications）；不读旧 run 的 evidence 与产物目录。自身 run 状态以编排方注入为准，不自行查证。
- **禁止全仓扫描**：不用 find / grep 全仓扫描寻找「参照实现」「惯例文档」（如 new-task.md）。上下文不足时向编排方回报缺什么，不自行探索。
- **禁止委派异步子代理**：异步委派会导致「回合完成≠交付落盘」，全部工作在本回合内亲自完成。
- **禁止修改门禁/钩子/策略类文件**：门禁、钩子、策略、权限类文件一律只读，发现需要改动时向编排方回报。
- **指令冲突按序取优先级**：编排方注入的上下文优先，其次本工单；不做超出两者授权的动作，拿不准即停并向编排方回报。
