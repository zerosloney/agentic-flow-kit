# API 切面（api）

> 由 `--surface api`（或 `--stack <stack>+api`）叠加；与 stack profile 同层，同名文件后声明的 surface 覆盖前者。

- **契约优先**：新增/修改接口先更新契约（OpenAPI / 类型定义），再实现；错误结构与状态码沿用既有约定。
- **测试**：接口变更必须覆盖集成测试（成功、校验失败、权限拒绝）；破坏性变更需版本化或显式迁移说明。
- **证据**：列出受影响的端点与调用方，附测试命令与结果；不凭“应该没问题”关单。
- **边界**：数据库结构变更归 `data` 切面；前端展示归 `frontend` 切面。
