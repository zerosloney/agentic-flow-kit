# 数据维护台账

本目录登记全项目数据维护 SQL 与执行状态，按阶段分类：

| 目录 | 用途 |
|---|---|
| `schema变更/` | 表结构变更（DDL），每个批次一个 `日期-主题/` 子目录 |
| `数据修复/` | 存量数据修复（DML），须写明影响行数与回滚口径 |
| `数据导入/` | 外部数据导入脚本与映射说明 |
| `查询/` | 只读排查 SQL |
| `备份/` | 备份与恢复脚本 |

## 硬约束

- 新增 SQL 必须登记执行状态与授权来源。
- 禁止无 `WHERE` 的全表 `DELETE` / `UPDATE`。
- 执行生产 SQL 属不可逆操作，须用户明确授权，且按项目数据维护台账与 DB 验证口径走。
- 脚本与台账示例见 `_TEMPLATE.md`（若存在）。

## 生成物

`README.md` 由本目录协议维护；具体批次清单以子目录与 git 历史为准。
