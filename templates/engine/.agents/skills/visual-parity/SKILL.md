# visual-parity — 视觉对齐

## 触发

原型 → 实现、旧页 → 新页、设计稿 → 页面，要求「看起来一致」。

## 0. 固定比较条件

同一视口（宽高 + DPR）、缩放 100%、同一主题、同一份数据（种子 ID 固定）。服务在线与鉴权按 `.agents/skills/verify-ui/SKILL.md` §1；技术细节单源 `scripts/verify/e2e/harness.mjs`。

## 1. 取对照

两侧各截同区域（含边界元素），命名 `tmp/e2e-evidence/parity-<topic>-{before,after}.png`。截图前重置滚动位置、关闭动画与 tooltip。

## 2. 差异分类（逐项计数）

间距 / 字号字重 / 颜色 / 层级与阴影 / 圆角 / 换行与溢出 / 滚动条。渲染噪声（字体抗锯齿、次像素）单列，不计入待修项。

## 3. 迭代

只改样式与布局，不改数据、不改后端、不引原型字体。每轮重截同区域；差异项只减不增。

## 4. 判据与证据

待修项 = 0 才算对齐；未清零不宣称「一致」。证据：两侧截图路径 + 视口 + 差异表（项 / 前 / 后 / 状态）。

## 红线

- 不弱化验证路径（`.agents/skills/verify-ui/SKILL.md`「禁为通过而弱化验证路径」）。
- 不以「肉眼看着一样」代替差异表。
