# 独立复核黄金集（golden-set）

> 校准资产：从已闭环 incident / papercut 提炼的「带已知答案」评审样本。
> 用途：①月度对账抽样比对独立复核结论与事后结果（mechanism-registry 登记）；②复核员 / 新会话自检——
> 对样本盲评后对答案，命中差 = 校准差。**每条样本必须带本项目上下文要点**（泛化样本无校准力）。
> 纪律：样本引用的是闭环时事实；对应代码后续演进不改已知答案（答案锚定当时的 incident 定性）。
> **随装状态**：本文件只带方法与格式，不带任何具体历史样本；项目按下方格式自行补样本（建议 ≥8 条、正负混合）。

## 使用方法

1. **盲评（双臂）**：遮住「已知答案 / 上下文要点」两列，按本技能双轴框架独立给结论——报/不报 + 级别（P0/P1/P2）+ 根因方向一句话。
   - **A 臂（默认）**：复核员装载本技能（含本项目回归清单与红线口径）。
   - **B 臂（对照，月度抽 5–8 条即可）**：把同样的题面交给**干净会话**，只给样本内联的仓库上下文，不载本技能。
   - **Δ = A 命中差 − B 命中差**是唯一能证明「上下文注入起作用」的数；两臂同样准说明校准力来自样本内联而非技能文档，两臂同样差说明该样本的已知答案不可判——两种情形都记进留痕表的「臂」列，不互相冒充。
2. **对答案**：三档记——**命中**（动作与定性同向：应报且档位/根因同向，或应放行且未报）；**误报**（应放行却报）；**漏报**（应报未报，或报了但根因方向错）。
3. **方差复跑**：同会话对**可疑判定**（与已知答案不符，或与常识相悖的轻松命中）原样再评一次；判定翻转 → 归**评分方差**（题面或 rubric 有歧义），本轮不计入命中差，另开 papercut 修题面；判定不翻转才计**校准差**。
4. **记录**：按月汇总填「月度盲评留痕」：月份 | 参评样本数 | 臂（A/B）| 命中/误报/漏报 | Δ | 方差复跑翻转次数 | 与 `workflow/reviews.d/` 当月片互参的备注。该片是复核事件级的「采纳/拒绝/误报」计数，本表是样本级命中差——两种粒度不混算，只在备注列关联。
5. **校准债**：命中差（误报+漏报 ÷ 参评样本数）连续两月 >20% → 在 `workflow/papercuts.d/` 当月片登记校准债，拟修指向角色契约 / 复核提示词条目。**前提**：先按第 3 步剔掉方差翻转的判定，否则评的是题面、不是复核员。

## 样本格式

每条样本一行，列含义：

| 列 | 含义 |
|---|---|
| # | 序号（增删用新号、不复用旧号） |
| 极性·类型 | 正例（应报）/ 负例（应放行）+ 问题类型（如「静态分析」「测试同步」「契约变更」） |
| 证据锚点 | incident / plan / spec 路径或 commit（可追溯） |
| 改动摘要 | 一句话说明改了什么 |
| 题面 | 给复核员的输入（不含答案） |
| 已知答案 | 应报/应放行 + 级别 + 根因方向一句话 |
| 上下文要点 | 做出正确判断所需的最小项目事实 |
