# SPEC — p2-batch1

## 功能行为

### A. --force 重装 owned 保护（审查 P2-1）

选定方案：**owned 例外跳过 + .bak 落底双保险**——

- renderTree 增 `protectOwned` 选项（init --force 路径启用）：rel 命中 `isOwned(rel)` 且目标已存在时，跳过覆盖（保持 owned「永不触碰」两态模型的一致延伸——sync 对 owned 已是同语义），打印 `跳过（owned 项目自持，--force 不覆盖）：<rel>`；
- **例外**：AGENTS.md 无骨架标记时仍走「文末追加补齐」（既有特例，非覆盖）；
- local-pre-commit 等已存在 owned 文件由此天然免覆盖，add-gate 接线不丢；
- 换 --hosts 重装的旧宿主目录孤儿：init 尾部提示「旧宿主目录文件已不在新宿主清单——如需清理手动删（kit.json 只记新宿主）」。

### B. 发布面 EOL 卫生（P2-2）

- 根 `.gitattributes` 补 `templates/_agents/hooks/local-pre-commit text eol=lf`（对齐装户侧模板 .gitattributes 自声明）；
- `package.json` prepack 扩为：清 cache（既有）+ **EOL 断言**——扫 `templates/` 全树（.sh/.mjs/.js/.cjs + 无扩展名钩子），任何文件含 `\r` 即 `console.error` 点名并 `process.exit(1)`（pack 失败 fail-fast）；
- 本仓 `templates/_agents/hooks/local-pre-commit` 若当前含 CR → renormalize 落 LF 一次。

### C. --board-port 校验（P2-3）

flags 与交互两路统一：非 `^(0|[1-9]\d*)$` 或越界 1-65535 → fail `--board-port 须为 1-65535 整数（现 <值>）`；交互模式就地重问一次（同宿主菜单风格）。

### D. init 输出语义（P2-4）

init 尾部（doctor 调用前）打印一行：`▶ flow-kit doctor（安装产物已就位；下方体检 FAIL 时本命令 exit 1——产物无损，按 FAIL 项处置）`。不改 doctor 本体异步结构（ 其打印顺序是 doctor 自身契约，牵动装户）。

### E. managed sha 残余面（papercuts 2026-09-27）

实现验证优先：closing-coverage 已归一 render 写盘 / sync 读取 / doctor §4 比对——预期本仓跑一次 `flow-kit sync` 即把台账内残留 CRLF sha 全部自愈刷齐（走「改动恰好等于新版」分支）。本批动作：①实测 sync → doctor §4 0 WARN + 克隆 0 managed WARN；②若实测仍有残余（如 kit.json 之外路径），按残余面补码；③papercuts 条目回填「已修」。

## 数据流

- A：init --force → renderTree(protectOwned) → owned 已存在跳过（.bak 不需要——跳过即零风险；审查原 .bak 方案仅当未来改回「覆盖+备份」语义时启用，本批选跳过故无 .bak 落盘）。
- B：git 属性 + prepack 双防线（检出归一 + 发布断言）。
- E：sync（LF 归一读取）→ kit.json 台账刷新 → doctor §4（LF 归一比对）。

## 约束遵守映射

- **owned 两态模型**：保护方案是「sync 永不触碰 owned」在 init --force 路径的对齐（此前不一致正是缺陷）。
- **发布物完整性**：EOL 断言在 prepack（pack 前必跑），不新增 CI 步骤。
- **双源纪律**：render/init 属 src/ 直改；templates/_agents/hooks/local-pre-commit 为包源件改后 sync 下发。
- **AGENTS.md 预算**：本批不动命令文档。

## 风险评估

| 风险 | 等级 | 缓解 |
|---|---|---|
| protectOwned 改变 --force 修复能力预期（用户想强制重置 owned 时无出口） | 中 | 提示语给出手动路径（删文件后重跑 / 手动合并）；owned 语义本就是「项目自持」 |
| prepack 断言误伤合法二进制/含 CR 的文本 | 低 | 扫描面限 templates/ 文本扩展名 + 无扩展名钩子；二进制（图片等）不在面内 |
| 端口校验破坏既有脚本传参 | 低 | 之前传非数字本就产出坏渲染；校验是 fail-fast 改善 |
| managed sha 实测仍有残余 | 低 | 残余面按实测补码（spec E②），不预设 |
| 回滚 | 低 | 单 feat 提交 revert 即回 |
