# Wiki index

> This directory is the project knowledge base, organized by topic. Board: `知识沉淀总览.html` (same directory, three-column mapping table).
>
> New installs start empty: place documents in the matching topic directory, then run `flow-kit run gen-wiki-board.mjs`; this index and the board are regenerated automatically.

| 主题 | 文件数 | 用途 |

## Naming rules

- Name new documents as `<日期>-<主题>/` or `<主题>-<名称>.md`.
- Paired documents (html/md) must be maintained in sync.
- Generated areas (overview table data rows, mapping table, board DATA) must not be hand-edited.
