# 风险级别路径提示清单（单源消费方：templates/_agents/scripts/level-criteria.mjs）
#
# 用途：登记「哪些路径一碰就**至少**是 L2 / L3」。定级是**意图面**的语义判定（「一处定义、多处消费」），
#       机器判不了语义；但「路径下限」可以登记，避免明显高风险的改动被拍脑袋判成 L1。
#       与 lane-surfaces.txt 的分工：那是**提交面**的触达判据（改这些面须有活跃 L2/L3 入口），
#       本文件是**意图面**的档位提示（改这些面就该按更高档走）。两者不同档，各司其职。
#
# 格式：每行一条 `<档位> <ERE>`，ERE 为 grep -E 兼容正则，匹配仓库相对路径（/ 分隔）。
#   档位**只收 L2 / L3**：本清单登记的是「一碰就至少是中/高风险面」的下限。L1 不构成门槛（L0 已退役），
#   登记了只会让提交面判低门（L2 触达面门）对无关改动出手——那正是要避免的噪声。
#   **ERE 与注释必须分两行**：写 `L3 ^a\.sql$  # 迁移 SQL` 会把 `# 迁移 SQL` 编进正则，
#   若含 $ 锚点该条就永不命中，且不报任何错（路径下限与提交面兜底同时静默失效）。
#   确需匹配路径里的 # 时写 \#。非法档位 / 行内注释 / 正则语法错 → **fail-loud 抛错**
#   （写错配置比没配置危险：没配置会提示补，写错会误判）。
#   # 注释与空行忽略；本文件缺失或清单为空 = 纯语义定级（判据面全程静默，不阻断）。
#
# 默认留空（刻意）：本清单内容是**项目私有**的——按你自己的代码布局登记，照抄别人的清单等于没登记。
# 建议起步：从「改什么几乎必然是 L2/L3」的高频面挑 3~5 条先登记，跑一段时间再补。
#
# ---- 示例（取消注释并按项目实际路径改写；本仓为 node 包源，下例仅示意形态）----
# # 迁移 SQL（注释单独成行，不要接在 ERE 后面）
# L3 ^src/db/migrations/.*\.sql$
# # schema 定义
# L3 ^src/db/schema/
# # 认证与中间件管线 / DI 链
# L3 ^(src/(auth|middleware)/|src/.*\.(auth|di)\.(ts|js)$)
# # 共享契约（DTO / 接口签名）
# L2 ^src/contracts/
# # 编码权威（取号 / 命名规则生成器）
# L2 ^src/coding/
